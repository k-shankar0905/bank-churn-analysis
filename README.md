# Bank Customer Churn Analysis

Exploratory Data Analysis on 10,000 bank customers 
to identify key factors driving customer churn.

## Tools Used
Python, pandas, seaborn, matplotlib, Jupyter Notebook

## Key Findings
- Germany has 2x higher churn than France and Spain
- Customers aged 40-60 are the highest churn risk
- Inactive members churn at nearly 2x the rate of active members
- Customers with 3+ products churn at nearly 100%

## Dataset
Kaggle — Churn Modelling Dataset (10,000 rows)
